CASSETTE J-CARD ARCHITECTURE

Every day is a tape. Side A and Side B.

Utter models daily speech history like a classic cassette J-card. Ruled cardstock, Side A morning tracks, Side B afternoon tracks, and zero cloud accounts.

Side A · Morning Session RUNNING TIME: 42 MIN
01

In-Process whisper Engine

Bundled small model loaded directly into local memory. No Ollama, no Docker, no external daemon required.

02

Direct Text Injection via System Accessibility

Simulates keystrokes directly into whichever window has active keyboard focus at sub-200ms latency.

03

Hands-Free Dictation Mode

Double-tap key to enter continuous dictation. Automatic silence detection commits sentences in real-time.

Side B · Afternoon Session RUNNING TIME: 38 MIN
04

Dual-Stream Meeting Transcription

Captures your microphone on track 1 and system audio (Zoom, Meet, Teams) on track 2 without uploading to any cloud bot.

05

On-Device Voice Transforms

Transform raw speech into structured bullet points, clean emails, or code snippets using local machine intelligence.

06

Desktop Robot Companion (CX-ArtLab)

An optional, delightful desktop companion rendered natively with hardware animation reacting to your voice states.
