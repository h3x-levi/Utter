Frequently Asked Questions

Everything you need to know.

How is Utter different from built-in macOS dictation? +

Built-in macOS dictation frequently times out, struggles with technical terms, and relies on proprietary cloud processing. Utter runs whisper.cpp locally with context biasing for programming keywords, multi-lingual support, and custom snippets.

Which Apple Silicon and Intel Macs are supported? +

Utter is compiled natively as a universal binary for Apple Silicon (M1/M2/M3/M4/Pro/Max/Ultra) with Metal acceleration and Intel Macs running macOS 13 (Ventura), macOS 14 (Sonoma), or macOS 15/26 (Sequoia).

How do I report bugs or request features? +

You can report issues directly inside the app via the Menu Bar dropdown (⌘I), Sidebar footer, or Diagnostics pane. It automatically compiles sanitized diagnostics and opens a 1-click GitHub issue.

Is Utter really 100% free and open source? +

Yes! Utter is 100% open source under the MIT License. There are no paywalls, subscriptions, or API usage fees.
